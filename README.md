# Student Performance Data Analysis

## Project Overview
This project analyses student academic performance using Python and data analysis libraries. The main objective is to identify patterns in student marks and understand how different factors relate to academic performance.

## Dataset
- **Dataset:** Student Performance Dataset
- **Source:** UCI Machine Learning Repository
- **Records:** 395 students
- **Columns:** 33
- **File:** student-mat.csv

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed
1. Loaded and explored the student dataset.
2. Identified column names, data types, and dataset information.
3. Calculated statistical measures.
4. Filtered high-performing students.
5. Sorted students based on final marks.
6. Grouped students according to study time.
7. Created five data visualizations.
8. Identified important patterns and insights.

## Visualizations
1. Distribution of Student Final Marks
2. Average Final Marks by Gender
3. Study Time vs Student Performance
4. First Period Marks vs Final Marks
5. Student Performance Correlation Heatmap

## Key Findings
- Average final grade: 10.42 out of 20.
- Highest final grade: 20.
- Lowest final grade: 0.
- Number of students scoring 15 or above: 73.
- Correlation between first-period and final marks: 0.80.
- Average number of absences: 5.71.

## Conclusion
This project demonstrates how Python libraries can be used to analyse real-world student data, perform statistical operations, visualize information, and identify meaningful patterns in academic performance.
